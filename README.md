# Web Based Tour Guide

**Module:** SE2030 Software Engineering · **Group:** 2026-Y2-S1-MLB-WEB3G1-03

A web application where tourists visiting Sri Lanka can find verified local guides,
browse tour packages with day-by-day itineraries, check a guide's availability,
book a tour, use seasonal offers, and leave a rating and review afterwards.

**Stack:** Node.js + Express (backend, all JavaScript) · React + Vite (frontend) ·
Microsoft SQL Server (database) · JWT authentication · raw parameterised T-SQL.
